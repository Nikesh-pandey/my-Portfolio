About JWT_SECRET
The JWT_SECRET is a secret key used in the process of generating and verifying JSON Web Tokens (JWTs). When a user logs in successfully, the server creates a JWT using the jwt.sign() function, where the JWT_SECRET is used to digitally sign the token. This signature ensures the token's authenticity and integrity, meaning it was generated by the server and hasn't been tampered with. Later, when the client sends the token back to access protected routes, the server uses the same JWT_SECRET with jwt.verify() to validate the token. If the token has been modified or wasn't signed using the correct secret, the verification will fail. This mechanism ensures that only tokens issued and signed by the server are considered valid, adding a layer of security to the authentication process.

In Mongoose, to store data in MongoDB, we first create an instance of our model using new Model(data). This instance represents a single document that follows the schema defined in the model. We then use the .save() method on this instance to save the document into the MongoDB collection. MongoDB stores data as documents, and Mongoose ensures that these documents comply with the schema, validations, and middleware by working with model instances. Therefore, it is necessary to always create an instance of the model before saving data, as MongoDB stores the data from these instances, not directly from the model definition itself.
